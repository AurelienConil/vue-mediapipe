# Minimal MediaPipe Version

Ce dossier contient une version ultra-minimale de l'intégration MediaPipe, sans Vue3, pour usage offline.

1. CameraCapture    → Capture vidéo
2. HandsDetector    → Détecte mains
3. CanvasManager    → Affiche la vidéo
4. LandmarksRenderer.render()    → Affiche landmarks bruts
5. GestureAnalysisChain         → Analyse (chain of responsability)
6. LandmarksRenderer.applyFeedback()  → Applique feedback visuel
